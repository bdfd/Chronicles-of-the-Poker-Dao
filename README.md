# 牌途问道录

> 以筹码为灵石，以牌桌为试炼场，于胜负无常与心魔起伏之间求索问道。

《牌途问道录》记录了我从一名初窥门径的牌修，踏上牌道修行之路的历程。

从懵懂入门，到渐悟牌局；从观察对手，到洞察人性；从执着胜负，到观照自我。这里写下的不只是牌局中的得失，也是在不确定中学习判断、克制与成长的过程。
