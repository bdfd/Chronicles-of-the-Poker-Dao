# 牌途问道录

> 以筹码为灵石，以牌桌为试炼场，于胜负无常与心魔起伏之间求索问道。

《牌途问道录》记录了我从一名初入山门的牌修，就此踏上牌道修仙大道。本书以修行手札的形式，记录牌理、术法、实战、心境与复盘所得，并将一路所学汇编成一部不断成长的牌道修行百科。
