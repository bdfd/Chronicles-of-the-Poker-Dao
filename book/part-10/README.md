# 第十卷：牌道百科

牌道之学，散于每一次下注、每一个决定，也藏在每一场胜负之后的反思之中。

本卷不再作为正文之外的附录，而是全书修行体系的一部分。各术语章分别对应前四章手札，将牌桌上的概念、修行中的体悟与可反复查阅的定义汇集于此。
