# 第十卷：牌道百科

牌道之学，散于每一次下注、每一个决定，也藏在每一场胜负之后的反思之中。

本卷不再作为正文之外的附录，而是全书修行体系的一部分。第一章对应序章与第一卷，第二章至第九章分别对应第二卷至第九卷正文，收录各部分首次出现的德州扑克专有词汇；同一词汇只在最早出现的部分中记录，并按英文名字依字母顺序排列。第十章单独收录牌道世界观词汇，第十一章收录贯穿九卷修行的道途成就。
