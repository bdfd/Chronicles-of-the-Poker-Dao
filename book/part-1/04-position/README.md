# 第一卷 第四章：位置先明 进退有度——Position（位置）

掌中双牌已有长短，席间先后亦有深浅。

同样的牌，先作决定与看过他人行动再作决定，所凭未必相同。

认清手牌，是辨掌中之器；察明 Position（位置），是看此器落在何处施展。

此番下副本，仍以八至九人 Full Ring（满员桌）的 Live Cash Game（线下现金桌）为修习之境。

初始 Buy-in（买入）与 Effective Stack（有效筹码），仍取 100–200 BB（大盲）作为推演基准。

不急着借位争先，先辨每次举筹以前，哪些行动已经看见，哪些回应尚未落定。

## 位不止名 更关所见

记住座次，只是认清阵位。

辨位之功，还在于看清：轮到行动时，比对手多看见了什么，又有哪些信息仍然未知。

后行可以先见他人的选择，却不能因此看穿底牌。

先行需要在后方回应未明时决定，也不意味着只能退守。

位置带来的是判断条件的差别，不是胜负的许诺。

本章不重列庄盲轮转，而从行动先后之中，辨认信息怎样影响取舍。

先看见多少，再问能够据此作何判断。

## 六门循序 由位入势

辨位有六门，由先后之别，行至借势之界。

1. 第一篇：先后有别 信息有差——Position（位置）  
   对照先行与后行，以 BTN（庄位）为镜，辨明多见一步所留下的选择余地。

2. 第二篇：多人同池 逐位辨明  
   逐一相照仍在局中的对手，不以对一人后行，误认对众人皆有位利。

3. 第三篇：同牌异位 取舍有别  
   尽量保持其余条件一致，只换阵位，观察同样双牌为何须重问进退。

4. 第四篇：盲位先投 不必恋池  
   看清后续位置、追加成本与参与人数，不让已落之筹牵住去留。

5. 第五篇：身后有人 尚未出手  
   留意翻牌前尚未行动者，不将未定的后续阵势，提前当作已有的位置优势。

6. 第六篇：位利虽在 亦有边界  
   将牌力、价格、筹码与对手行动一并核对，以位置清单收束借势之法。

六门所求，不是记下一句“后位便可进”。

而是每逢局势变化，都能重新辨明：相对谁先行，相对谁后行，眼前所见又能支持什么。

## 手札一记

辨位不止记名，借势仍须有据。多见一步，莫作看透全局。
