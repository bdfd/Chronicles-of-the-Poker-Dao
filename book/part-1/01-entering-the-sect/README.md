# 第一卷 第一章：初入山门 始知敬畏

第一次走进八人现金桌，才知背得规矩与身在牌阵是两回事。

本章六篇，从辨认投入、守住次序，到护牌、求证、照见偶得胜局中的错念，最后带着未解之问走向下一章。

## 六篇次第 循序入门

1. [第一篇：初见牌毡 先量灵石——Buy-in（买入）](01-first-table-and-buy-in.md) 先认清入座时所带筹码与风险。
2. [第二篇：筹声纷起 莫失次序——Action（行动）](02-action-order.md) 在声浪中等到属于自己的行动。
3. [第三篇：底牌入手 先护其机——Hole Cards（底牌）](03-hole-cards.md) 守住底牌与尚未公开的信息。
4. [第四篇：问规不怯 宁缓一息](04-ask-before-acting.md) 不明之处先问清，再自行决定。
5. [第五篇：一池偶得 照见错念——Variance（方差）](05-win-and-variance.md) 分开偶得的胜局与失据的跟注。
6. [第六篇：归山回望 敬畏始生](06-return-with-questions.md) 留下具体疑问，循规继续修行。

## 手札一记

山门之初，先认所知有限；守住次序，记下疑处，方能再学规矩。
