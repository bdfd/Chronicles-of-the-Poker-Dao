# 第一卷：初入山门

从[序章：牌界初观](00-world-of-poker.md)走入此卷，我第一次真正坐上牌桌，也终于明白：知道规则，并不等于已经入门。真正踏入山门，不是记住 Hand Ranking（牌型大小）便算入道，而是承认自己所知有限，愿意从最基本的规矩学起。

初坐 Live Cash Game（线下现金桌）的 Full Ring（满员桌），筹码声、Table Talk（桌上交谈）与输赢带来的刺激，常令人急于证明自己。本卷不追求复杂术法，只练三件事：尊重 Action（行动）次序，保护 Hole Cards（底牌），并为每一次 Bet（下注）、Call（跟注）与 Fold（弃牌）留下能够复盘的理由。

本卷由[第一卷 第一章：初入山门](01-entering-the-sect.md)展开个人手札。从认识规则、敬畏未知开始，学习不把一时获胜误作天赋，也不把一次失利视为退境。

随后进入[第一卷 第二章：德扑的规矩](02-poker-rules/README.md)，依十篇次第辨明牌室边界、成牌方法、行动顺序、下注规则、摊牌裁定与同桌戒律。

山门不在牌桌之外。

当我愿意承认尚未看懂，并对自己的每一个决定负责，修行才真正开始。
