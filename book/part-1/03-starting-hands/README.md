# 第一卷 第三章：手牌初辨 取舍有据

规矩既明，牌阵已有章法；两张底牌在手，取舍却未必有根。

高张看似锋利，对子似有根基，同花连张又藏着成牌的想象。若只看见可喜之处，便容易把尚未发生的结果，当成此刻入池的凭据。

牌有长短，不凭喜恶。

同样的 Hole Cards（底牌），放在不同位置，面对不同投入，未必适合相同的选择。牌名不会替人辨势，成牌潜力也不会免去投入的代价。

初辨手牌，便是先看清掌中之物。

哪里已有根基，哪里仍待改善，哪里看似得势，却可能受制，都应逐步辨明。

此番下副本，仍在八至九人 Full Ring（满员桌）的 Live Cash Game（线下现金桌）中辨牌察势。

推演牌局时，将初始 Buy-in（买入）与 Effective Stack（有效筹码）设在 100–200 BB（大盲）之间。

先识手牌，再察局势；取舍有据，方可举筹。

## 六门次第 由形入局

辨牌有六门。

依次走过，从认清双牌之形，行至审视入池之据。

1. 第一篇：强弱初辨 莫执牌名  
   从点数、对子、花色与连接性辨认手牌，不以熟悉牌名代替判断。

2. 第二篇：口袋成对 各有深浅——Pocket Pair（口袋对子）  
   同为掌中成对，仍须分清强弱、潜力与受制之处。

3. 第三篇：同花相连 莫许奇功——Suited Connectors（同花连张）  
   看见成顺、成花的可能，也看清潜力尚未兑现时的限制。

4. 第四篇：高牌受制 须辨踢脚——Kicker（踢脚牌）  
   高张成对未必无忧，须防弱踢脚使看似得势之牌反受牵制。

5. 第五篇：入池之前 先察局势  
   举筹以前，察明前方行动、投入金额、身后玩家与有效筹码。

6. 第六篇：边缘难决 先守所知  
   将取舍归为清单，列清判断依据，记下尚待求证的缺口。

## 修习有序 取舍有据

六门辨牌，由形入势。

先看两张牌如何相连，再看眼前局势是否容得下这份潜力。

对子已有牌型，却不能因此忽略后来者。花色与点数有所呼应，也不能将尚未成形的强牌提前算入掌中。

高张是否容易受制，成对以后踢脚是否薄弱，都须在入池以前有所察觉。

看过手牌，还要看回牌桌。

前方无人参与，与已经有人加注，不是同一道关。身后尚有玩家，也不能只把眼前一人当作全部对手。

最后一门，是把所知落成取舍。

能够说明为何参与，也能说明为何退出；尚有疑处，便如实记下，留待复核。

辨牌不是寻一手必胜之牌，而是减少无据入局。

掌中看得清，举筹才不易随念而动。

## 手札一记

先辨双牌长短，再察入池所据。

不以喜恶代判断，取舍方能扎根。
