# 第一卷 第二章 第八篇：孤注分池 各守其界——All-in（全下）

All-in（全下），只是押尽自身灵石。

筹码较少者可以投入全部，却不能迫使筹码较多者只争同一层底池。投入有深浅，争夺也会随之分层。

孤注可尽，因果不可越界。

## 全下只尽己筹

玩家进行 All-in（全下）时，将当前剩余的全部 Stack（筹码量）投入牌局。

若筹码少于当前 Call（跟注）金额，仍可 All-in（全下），但只投入自身拥有的筹码。

其他玩家不需要把下注降低到短筹码金额。他们仍须依当前合法下注继续行动。

All-in（全下）玩家不会因为投入较少，便失去已经匹配部分的争夺资格；也不会因为牌力最强，便取得自己从未匹配的额外筹码。

能争多少，只看投入到了哪一层。

## Main Pot（主池），人人同争

每名相关玩家都能匹配的部分，构成 Main Pot（主池）。

假设四名玩家最终投入：

- 玩家A：40
- 玩家B：100
- 玩家C：150
- 玩家D：150

最短筹码为40。

每人先取40进入 Main Pot（主池）：

40 × 4 = 160。

玩家A、B、C、D都有资格争夺这160。

玩家A若获胜，只能取得 Main Pot（主池），不能取得其余玩家在40以上继续投入的筹码。

## Side Pot（边池），逐层分开

扣除每人进入 Main Pot（主池）的40后：

- 玩家B剩余投入60。
- 玩家C剩余投入110。
- 玩家D剩余投入110。

B、C、D各取60，形成第一只 Side Pot（边池）：

60 × 3 = 180。

再扣除60后，C与D各剩50，形成第二只 Side Pot（边池）：

50 × 2 = 100。

最终结构如下：

| 底池 | 金额 | Eligible Player（有资格争夺的玩家） |
|---|---:|---|
| Main Pot（主池） | 160 | A、B、C、D |
| 第一只 Side Pot（边池） | 180 | B、C、D |
| 第二只 Side Pot（边池） | 100 | C、D |

每只底池独立判定胜者。

A可能赢得 Main Pot（主池），B可能赢得第一只 Side Pot（边池），C或D则可能赢得第二只 Side Pot（边池）。

同一副牌，可以产生多个胜者。

## 未被匹配，应当退回

只有得到对手匹配的筹码，才能进入 Pot（底池）。

若玩家A Bet（下注）100，唯一对手玩家B只有60并 All-in（全下），那么多出的40没有被任何人匹配。

这40属于 Uncalled Bet（未获跟注的下注），应退还玩家A，不能算入 Main Pot（主池）。

已被匹配的部分进入底池，未被匹配的部分归还原主。

灵石有来处，也必须有对应的争夺者。

## 有人全下，牌局未必结束

一名玩家 All-in（全下）以后，只是失去继续下注的能力。

若仍有两名或以上玩家保有筹码，他们可以继续 Bet（下注）、Call（跟注）或 Raise（加注），并形成新的 Side Pot（边池）。

只有所有仍在局中的玩家都已 All-in（全下），或仅剩一名玩家仍有筹码可行动时，后续才不再产生新的下注。

此后由 Dealer（发牌员）完成剩余公共牌。是否允许 Run It Twice（发两次公共牌），仍以 House Rules（牌室规则）为准。

## 分池交给 Dealer（发牌员）

出现多个 All-in（全下）时，不要自行把 Pot（底池）分成几堆。

保持已投入筹码原状，让 Dealer（发牌员）核对每名玩家的总投入，并依次建立 Main Pot（主池）与 Side Pot（边池）。

进入 Showdown（摊牌）后，各只底池应分别判定。后形成的 Side Pot（边池）通常先处理，再逐层回到 Main Pot（主池）。

玩家需要做的，是确认自己的总投入与争夺资格，不是伸手移动底池。

## 初修易错

全下分池中，常见错误有四：

- 认为最强牌可以赢得桌面全部筹码。
- 把未获匹配的筹码留在 Pot（底池）中。
- 忘记已经 All-in（全下）的玩家不能争夺后续 Side Pot（边池）。
- 多名玩家全下后，自行移动或合并底池。

分池看似繁复，根基只有一句：

同额相争，超额另立。

## 手札一记

All-in（全下）只能押尽自身灵石；同额入主池，超额立边池，未获匹配者归还。

## 本篇三省

1. 面对不同 Stack（筹码量）的 All-in（全下），是否能按每层共同投入计算底池？
2. 是否曾把未被匹配的筹码误算进 Pot（底池），或让短筹码争夺后续边池？
3. 下一次出现多人 All-in（全下）时，应如何记录每名玩家的总投入与争夺资格？
