# 第一卷 第二章：德扑的规矩

初入山门，识得牌型，不过看见门楣；懂得规矩，才算真正跨过门槛。

方寸牌桌，是一座时刻流转的阵。

BTN（庄位）逐手轮转，Blinds（盲注）依位落下，筹码随言语与动作汇入 Pot（底池）。有人抢行一步，提前泄露意图；有人错说一字，将选择交给规则；也有人握着胜牌，却在 Showdown（摊牌）前将 Hole Cards（底牌）送入弃牌堆。

牌技未必输，规矩却已错。

规则不是缚手的锁链，而是牌阵的界纹。它划定行动先后，也厘清筹码归属。界纹若乱，再高明的术法也无处落脚。

本章以八至九人的 Live Cash Game（线下现金桌）为主要场景。默认初始 Buy-in（买入）与 Effective Stack（有效筹码）为 100–150 BB（大盲）。若通用惯例与牌室规定不同，以 House Rules（牌室规则）及 Floor Ruling（牌室主管裁定）为准。

先知边界，再谈术法；先守规矩，方能问道。

## 十篇次第

牌阵有十门。

依次走过，方能从安然入座，行至明正定胜。

1. [第一篇：入座立界——House Rules（牌室规则）与 Table Stakes（桌面筹码规则）](01-house-rules-and-table-stakes.md)  
   先问界，再落座。买入、补筹、抽水与桌面筹码皆有规制，灵石不可不明不白地入阵。

2. [第二篇：庄盲定位——BTN（庄位）、Blinds（盲注）与 Position（位置）](02-button-blinds-and-position.md)  
   一钮转，庄盲移。辨明 Position（位置），方知身在阵前、阵中，还是阵后。

3. [第三篇：成牌之法——Best Five-Card Hand（最佳五张成牌）](03-best-five-card-hand.md)  
   暗牌二，公牌五，七取其强五。牌型、点数与踢脚牌层层相较，最终只留一手定胜。

4. [第四篇：四街行法——Street（下注轮次）与 Action（行动）](04-streets-and-actions.md)  
   牌行四街，如过四关。每条 Street（下注轮次）皆有始终，每次 Action（行动）皆有先后。

5. [第五篇：注有法度——Betting Structure（下注结构）与 Minimum Raise（最低加注）](05-betting-and-raising.md)  
   注可无上限，举筹不可无尺度。算清 Betting Structure（下注结构）与 Minimum Raise（最低加注），方能让筹码合法落定。

6. [第六篇：一言定注——Verbal Declaration（口头声明）与 Chip Action（筹码动作）](06-verbal-and-chip-actions.md)  
   言出有凭，筹落有据。Verbal Declaration（口头声明）与 Chip Action（筹码动作）若不清楚，原有选择便可能随之消散。

7. [第七篇：孤注分池——All-in（全下）、Main Pot（主池）与 Side Pot（边池）](07-all-in-and-side-pots.md)  
   孤注一推，只尽自身灵石，并非通吃全局。筹码有深浅，Main Pot（主池）与 Side Pot（边池）便各有因果。

8. [第八篇：护牌定胜——Showdown（摊牌）、Muck（弃牌／弃牌堆）与 Cards Speak（牌面为准）](08-showdown-and-hand-protection.md)  
   牌藏于手，胜定于桌。进入 Showdown（摊牌），须护牌、亮牌、辨牌；一旦误入 Muck（弃牌／弃牌堆），强牌也可能沉寂无声。最终高下，只由 Cards Speak（牌面为准）。

9. [第九篇：乱局有裁——Misdeal（错发重发）、Action Out of Turn（越位行动）与 Floor Ruling（牌室主管裁定）](09-misdeal-and-floor.md)  
   牌阵有误，最忌各行其是。遇到 Misdeal（错发重发）或 Action Out of Turn（越位行动），应停手留局，请求 Floor Ruling（牌室主管裁定）。

10. [第十篇：同桌守正——Game Integrity（牌局公正）与 Table Etiquette（牌桌礼仪）](10-game-integrity-and-etiquette.md)  
    牌可以争，局不可污。守住 Game Integrity（牌局公正）与 Table Etiquette（牌桌礼仪），方能不负同桌，也不负道心。

## 修习之序

十门规矩，环环相扣。

入座前，先确认牌室边界。取得手牌后，再依庄位与盲注辨明次序。

知成牌，才能定高下；懂四街，才能依序而行。

下注时，既要算清金额，也要准确表达。有人 All-in（全下）以后，还须划分各方能够争夺的底池。

进入 Showdown（摊牌），仍要保护手牌并核对结果。若牌局生乱，不可擅自翻牌、收筹或重排 Pot（底池）。

最后一门，是守正。

牌桌容许竞争，不容许共谋；容许观察，不容许泄露；容许思考，不容许借规则的含混欺骗同桌。

修习规矩，不是为了逞一时口舌，而是为了少生争议。即使乱局已起，也能心中有尺，行动有度。
