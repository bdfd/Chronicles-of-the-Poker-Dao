# 第一卷 第二章：入局先明 牌桌规矩

初入山门，识得牌型，不过看见门楣；懂得规矩，才算真正跨过门槛。

方寸牌桌，是一座时刻流转的阵。

BTN（庄位）逐手轮转，Blinds（盲注）依位落下，筹码随言语与动作汇入 Pot（底池）。有人抢行一步，提前泄露意图；有人错说一字，将选择交给规则；也有人握着胜牌，却在 Showdown（摊牌）前将 Hole Cards（底牌）送入弃牌堆。

牌技未必输，规矩却已错。

规则不是缚手的锁链，而是牌阵的界纹。它划定行动先后，也厘清筹码归属。界纹若乱，再高明的术法也无处落脚。

本章以八至九人的 Live Cash Game（线下现金桌）为主要场景。默认初始 Buy-in（买入）与 Effective Stack（有效筹码）为 100–200 BB（大盲）。若通用惯例与牌室规定不同，以 House Rules（牌室规则）及 Floor Ruling（牌室主管裁定）为准。

先知边界，再谈术法；先守规矩，方能问道。

## 修习之序

十一门规矩，环环相扣。

先守通则，再确认牌室边界。取得手牌后，再依庄位与盲注辨明次序。

知成牌，才能定高下；懂四街，才能依序而行。

下注时，既要算清金额，也要准确表达。有人 All-in（全下）以后，还须划分各方能够争夺的底池。

进入 Showdown（摊牌），仍要保护手牌并核对结果。若牌局生乱，不可擅自翻牌、收筹或重排 Pot（底池）。

最后一门，是守正。

牌桌容许竞争，不容许共谋；容许观察，不容许泄露；容许思考，不容许借规则的含混欺骗同桌。

修习规矩，不是为了逞一时口舌，而是为了少生争议。即使乱局已起，也能心中有尺，行动有度。
