# 第三卷 第二章：牌桌众生谱：十六门数字画像-Player Type（玩家类型）

一张牌桌，便是一方小世界。有人守牌如守山门，有人出手似惊雷裂空；有人愿随众入池看尽五街，也有人稍遇压力便抽身远遁。牌修若只凭一两次行动替对手定性，所见不过浮影；唯有把长期行动化作可复查的数字，才可能从众生百态中辨出相对稳定的规律。

本章以8—9人桌 Live Cash Game（线下现金局）为主要场景，以初始 Buy-in（买入）100—150 BB（大盲）为基准，将常见 Player Type（玩家类型）录为十六门数字画像。门派之名只是方便记忆的修仙化称谓，不代表玩家身份、人品或永远不变的打法。

## 画像戒律

- 十六门可以重叠。一名玩家可以玄衡剑宗为主画像，同时带有潜龙伏渊宗的慢打特征。
- 数字只描述已经出现的行动。30手以内只记录具体行为，不作稳定定型。
- 50—99手可以建立临时 Opponent Profile（对手画像）；VPIP（主动入池率）与 PFR（翻牌前加注率）至少观察150手后，才适合用于较稳定的分类。
- 3-Bet%（三次下注率）至少需要20次可进行 3-Bet（三次下注）的机会；Fold to C-Bet（面对持续下注弃牌率）至少需要15次对应机会。
- Turn（转牌）与 River（河牌）的倾向至少需要10次对应机会。若机会不足，应记录为“样本不足”，不得用百分比制造确定感。
- 线下手工统计采用“实际次数／有效机会数”。例如20手中主动入池8手，VPIP便为40%。

## 牌桌众生谱：十六门数字画像

| **玄龟封山宗** | Nit（极紧玩家） | VPIP为6%—12%；PFR为4%—9%；3-Bet%为0%—3%；VPIP与PFR相差不超过4个百分点。 |

| **寒蝉藏锋谷** | Weak-Tight Player（紧弱玩家） | VPIP为12%—20%；PFR为7%—14%；Fold to 3-Bet（面对三次下注弃牌率）不低于75%；Fold to Flop C-Bet不低于65%；面对 River Bet（河牌下注）的弃牌率不低于70%。 |
| **照影断念宗** | Fit-or-Fold Player（中牌则战、不中则弃型玩家） | Fold to Flop C-Bet不低于70%；跟注翻牌前加注后，面对 Flop C-Bet继续游戏的比例不超过30%；在已确认未击中对子或有效 Draw（听牌）的牌例中，弃牌比例不低于80%。 |
| **惊鸿遁甲门** | Overfolder（过度弃牌玩家） | 以下四项至少满足两项：Fold to 3-Bet不低于75%；Fold to Flop C-Bet不低于70%；Fold to Turn Barrel（面对转牌连续下注弃牌率）不低于65%；Fold to River Bet（面对河牌下注弃牌率）不低于65%。 |
| **青藤随行派** | Limp-Caller（跛入跟注型玩家） | 有机会 Limp（跛入）时，Limp Frequency（跛入频率）不低于30%；PFR不超过8%；跛入后面对 Isolation Raise（隔离加注）的跟注率不低于60%。 |
| **正一循矩院** | ABC Player（基础套路型玩家） | VPIP为16%—24%；PFR为11%—18%；两者相差不超过7个百分点；3-Bet%为3%—7%；在至少10次已摊牌的同类牌力中，采用相同 Bet Sizing（下注尺度）的比例不低于75%。 |
| **潜龙伏渊宗** | Trapper（设陷型玩家） | 在至少10次已确认的强牌机会中，首次获得 Bet或Raise机会时选择 Check（过牌）或 Call（跟注）的比例不低于40%；采取被动线路后在Turn或River加注的比例不低于25%。 |
| **千幻迷踪门** | Overbluffer（过度诈唬玩家） | 至少观察10次进入Showdown的River Bet，其中 Bluff（诈唬）占比不低于40%；或在至少10次已确认的错失听牌机会中，River下注率不低于60%。 |
| **百炼定元堂** | Standard-Stack Player（标准筹码玩家） | 初始Buy-in为100—120 BB；筹码低于80 BB时补码；至少80%的观察手数将 Stack（筹码量）维持在80—120 BB。 |
| **渊海长策阁** | Deep-Buy Player（深买入型玩家） | 初始Buy-in为130—150 BB；至少80%的观察手数保持不低于120 BB；与另一名玩家均持有至少120 BB时，才把该手牌记录为较深 Effective Stack（有效筹码）局面。 |
| **金蟾万宝楼** | Whale（高额娱乐玩家） | 同时满足以下条件：VPIP不低于45%；初始Buy-in为150 BB；四小时内累计Buy-in不低于450 BB；面对翻牌前Raise的跟注率不低于60%。单凭输掉三个买入不得归入此门。 |
| **无相万化宗** | Adaptive Reg（适应型常客玩家） | 当对手连续3次使用同一种剥削动作后，能在接下来5次相同或相近机会中至少调整2次；相邻两个50手窗口中，VPIP、PFR或3-Bet%至少有一项变化不低于5个百分点，并有行动或Showdown证据表明变化具有针对性。 |

## 主画像与副画像

十六门并非互斥分类。记录时应选一个最能解释当前行动的主画像，再补充一至两个副画像，并在新证据出现后重新判断。

例如，观察一名玩家50手，得到以下记录：

- 主动入池22手，VPIP为44%。
- 翻牌前加注5手，PFR为10%。
- 跛入后面对加注8次，其中跟注6次，跛入跟注率为75%。
- 面对Flop C-Bet共10次，其中弃牌3次，Fold to Flop C-Bet为30%。

这名玩家符合沧海听潮门与青藤随行派的多项数字线，因此可暂记为：

> 主画像：Calling Station（跟注站）；副画像：Limp-Caller（跛入跟注型玩家）；当前样本：50手；置信程度：临时。

这样的记录比“打法很松”“喜欢跟注”更容易验证。若后续100手中数据明显改变，就应修改画像，而不是替旧判断寻找借口。

## 筹码口径

本章只用BB记录买入与筹码，不使用具体货币金额。初始Buy-in为100—150 BB，并不代表一手牌必然拥有同样的Effective Stack；两名玩家分别持有150 BB与85 BB时，双方实际能够相互投入的Effective Stack只有85 BB。

因此，百炼定元堂与渊海长策阁描述的是买入及持码习惯，不直接证明技术强弱。金蟾万宝楼则必须同时满足行动与资金投入条件，不能仅凭买入次数或一场亏损对玩家贴上标签。

## 谱后手札

我曾以为，给对手起一个名字，便算看懂了对手。后来才知，名字只是索引，数字只是证据，真正的判断仍须回到具体的Position（位置）、Range（范围）、筹码深度与行动历史。

同一名牌修，可能在Preflop（翻牌前）显出玄衡剑宗的克制，到了River却带着惊鸿遁甲门的退意；也可能平日遵循正一循矩院的章法，遭逢Tilt（情绪失控）后忽入赤焰狂刀宗。观人之术，不是问他永远属于哪一门，而是问：

> 此时、此位、此等Effective Stack之下，他正在使用哪一门的功法？

## 本章牌道术语

| 英文名称或缩写 | 中文含义 | 简要释义 |
|---|---|---|
| Player Type | 玩家类型 | 按照可重复观察的范围、频率、筹码或行动特征划分的玩家类别。 |
| Live Cash Game | 线下现金局 | 玩家在实体牌桌面对面进行、筹码具有现金价值的牌局。 |
| Buy-in | 买入 | 玩家进入牌局时换取的初始筹码数量。 |
| BB | 大盲 | 本章用于表示买入与筹码深度的统一单位。 |
| Opponent Profile | 对手画像 | 根据长期行动与摊牌证据整理出的对手特征记录。 |
| VPIP | 主动入池率 | 玩家在翻牌前主动投入筹码参与底池的手数比例，不计被迫投入的盲注。 |
| PFR | 翻牌前加注率 | 玩家在翻牌前进行加注的手数比例。 |
| 3-Bet% | 三次下注率 | 玩家获得3-Bet机会时选择再次加注的比例。 |
| 3-Bet | 三次下注／再加注 | 面对前方首次加注时进行的下一次加注。 |
| Fold to C-Bet | 面对持续下注弃牌率 | 玩家面对C-Bet时选择弃牌的比例。 |
| Fold to Flop C-Bet | 面对翻牌持续下注弃牌率 | 玩家在Flop面对C-Bet时选择弃牌的比例。 |
| Fold to 3-Bet | 面对三次下注弃牌率 | 玩家率先加注后面对3-Bet时选择弃牌的比例。 |
| Fold to Turn Barrel | 面对转牌连续下注弃牌率 | 玩家跟注Flop下注后，面对Turn继续下注时选择弃牌的比例。 |
| Fold to River Bet | 面对河牌下注弃牌率 | 玩家到达River并面对下注时选择弃牌的比例。 |
| Nit | 极紧玩家 | 使用极窄范围入池、很少主动争夺边缘底池的玩家。 |
| TAG | 紧凶玩家 | 使用相对克制的入池范围，并以主动下注和加注为主的玩家。 |
| LAG | 松凶玩家 | 使用较宽范围入池，并以较高频率主动施压的玩家。 |
| Maniac | 极度激进玩家 | 以异常高频率下注、加注和制造大底池的玩家。 |
| Calling Station | 跟注站 | 跟注频率过高、弃牌和加注频率不足的玩家。 |
| Weak-Tight Player | 紧弱玩家 | 入池范围较窄，并在面对压力时弃牌过多的玩家。 |
| Fit-or-Fold Player | 中牌则战、不中则弃型玩家 | 在Flop与牌面形成对子或听牌时继续，否则经常立即弃牌的玩家。 |
| Overfolder | 过度弃牌玩家 | 在一个或多个决策节点的弃牌频率超过合理防守需要的玩家。 |
| Limp-Caller | 跛入跟注型玩家 | 经常Limp入池，并在面对隔离加注后继续跟注的玩家。 |
| ABC Player | 基础套路型玩家 | 主要依照基础、直接且较少变化的路线行牌的玩家。 |
| Trapper | 设陷型玩家 | 经常用强牌采取过牌或跟注，等待对手继续投入筹码的玩家。 |
| Overbluffer | 过度诈唬玩家 | 在特定节点放入超过合理比例诈唬组合的玩家。 |
| Standard-Stack Player | 标准筹码玩家 | 主要以100 BB附近的筹码深度参与牌局并主动补码的玩家。 |
| Deep-Buy Player | 深买入型玩家 | 在本章100—150 BB基准中，主要选择130—150 BB初始买入的玩家。 |
| Whale | 高额娱乐玩家 | 投入筹码规模较大，并通常采用宽松娱乐打法的玩家。 |
| Adaptive Reg | 适应型常客玩家 | 能够识别对手的重复调整，并主动改变自身频率与路线的常客玩家。 |
| Bet | 下注 | 当前轮次尚无人下注时率先投入筹码。 |
| Raise | 加注 | 在已有下注的基础上进一步提高投入金额。 |
| Call | 跟注 | 补足当前最高下注金额并继续参与底池。 |
| Check | 过牌 | 当前无人下注时不投入筹码，并把行动权交给下一位玩家。 |
| Bluff | 诈唬 | 以较弱手牌下注或加注，试图迫使更强手牌弃牌。 |
| Limp | 跛入 | 翻牌前在无人加注时只跟入一个大盲。 |
| Limp Frequency | 跛入频率 | 玩家获得跛入机会时选择Limp的比例。 |
| Isolation Raise | 隔离加注 | 面对一名或多名跛入者加注，试图减少入池人数并取得主动权。 |
| Bet Sizing | 下注尺度 | 一次下注或加注所选择的筹码数量及其相对底池的比例。 |
| Draw | 听牌 | 尚未完成，但可能通过后续公共牌改善的手牌。 |
| Flop | 翻牌 | 同时发出的前三张公共牌及相应下注轮次。 |
| Turn | 转牌 | 第四张公共牌及相应下注轮次。 |
| River | 河牌 | 第五张公共牌及最后一个下注轮次。 |
| River Bet | 河牌下注 | 在River轮次进行的下注。 |
| Showdown | 摊牌 | 下注结束后，仍在局中的玩家展示底牌并比较牌力。 |
| Stack | 筹码量 | 玩家当前在牌桌上可用于下注的筹码总量。 |
| Effective Stack | 有效筹码 | 任意两名玩家在一手牌中实际能够相互投入的最大筹码量。 |
| Position | 位置 | 玩家相对庄家按钮及其他玩家的行动次序。 |
| Range | 范围 | 玩家在特定局面中可能持有的一组手牌。 |
| Preflop | 翻牌前 | 底牌发出后、Flop出现前的首轮行动阶段。 |
| Tilt | 情绪失控 | 情绪干扰正常判断并导致策略明显偏离的状态。 |
