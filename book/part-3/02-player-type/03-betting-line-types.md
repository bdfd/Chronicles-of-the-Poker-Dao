# 第二章第三篇：行牌四门——四街留痕，招式有迹

入局范围只能说明一名玩家带着哪些牌进入底池，却不能说明他将如何走完一手牌。

有人习惯随众跛入，有人严格依照基础章法，有人以强牌示弱设伏，也有人幻术过盛，在不适合诈唬的地方依旧强行施压。

从 Preflop（翻牌前）到 River（河牌），连续的 Betting Line（下注路线）如同功法运转留下的灵力轨迹。观察次数足够后，重复的招式便会显形。

## 第一门：青藤随行派

青藤随行派对应 Limp-Caller（跛入跟注型玩家）。

其 Limp Frequency（跛入频率）不低于30%，PFR（翻牌前加注率）不超过8%；跛入后面对 Isolation Raise（隔离加注）的跟注率不低于60%。

青藤不争先，却善随行。此类玩家经常先以 Limp（跛入）进入底池，面对加注后又不愿离去，使牌局形成 Multiway Pot（多人底池）。

### 本门所长

- 能以较低成本观看翻牌。
- 宽范围使具体牌力难辨。
- 部分牌能获得较高隐含赔率。

### 功法破绽

- 主动权交给后方玩家。
- 经常以弱牌进入多人底池。
- 身处不利位置时难以兑现权益。

### 破局心法

- 在有利位置进行 Isolation Raise（隔离加注）。
- 根据跛入人数提高加注尺度。
- 进入多人底池后减少 Bluff（诈唬）。

## 第二门：正一循矩院

正一循矩院对应 ABC Player（基础套路型玩家）。

其 VPIP（主动入池率）为16%—24%，PFR（翻牌前加注率）为11%—18%，两者相差不超过7个百分点；3-Bet%（三次下注率）为3%—7%。在至少10次已摊牌的同类牌力中，采用相同 Bet Sizing（下注尺度）的比例不低于75%。

此门依基础章法行牌：强牌主动取值，弱牌较少强行争夺，常见局面的处理直接而稳定。

### 本门所长

- 基础稳固，严重错误较少。
- 行动直接，执行难度较低。
- 不易因短期输赢改变策略。

### 功法破绽

- 路线固定，容易泄露牌力。
- 对不同对手调整不足。
- 异常尺度往往暴露信息。

### 破局心法

- 记录不同牌力对应的下注尺度。
- 寻找持续出现的固定路线。
- 对偏离常态的行动提高警惕。

## 第三门：潜龙伏渊宗

潜龙伏渊宗对应 Trapper（设陷型玩家）。

在至少10次已确认的强牌机会中，其首次获得 Bet（下注）或 Raise（加注）机会时，选择 Check（过牌）或 Call（跟注）的比例不低于40%；采取被动路线后，在 Turn（转牌）或 River（河牌）加注的比例不低于25%。

潜龙藏于深渊，强牌未必立即显锋。此类玩家常以过牌或跟注隐藏牌力，等待对手继续投入。

### 本门所长

- 能够诱使对手继续诈唬。
- 强牌进入被动范围后更难判断。
- 面对激进玩家容易获得额外支付。

### 功法破绽

- 容易给予听牌免费改善机会。
- 强牌未必能及时扩大底池。
- 过度慢打会使范围失衡。

### 破局心法

- 不把 Check（过牌）自动视为弱势。
- 持有边缘牌时控制底池。
- 记录其在哪条下注轮次开始反击。

## 第四门：千幻迷踪门

千幻迷踪门对应 Overbluffer（过度诈唬玩家）。

至少观察10次进入 Showdown（摊牌）的 River Bet（河牌下注）；若其中 Bluff（诈唬）占比不低于40%，便显出千幻之象。另一条判断线，是在至少10次已确认的错失听牌机会中，其河牌下注率不低于60%。

千幻之术重在让对手无法相信自己的牌力。但若幻术使用过多，Value Range（价值范围）便不足以支撑整体下注频率。

### 本门所长

- 能迫使较强牌错误弃牌。
- 下注范围难以直接判断。
- 激进形象能为强牌获得支付。

### 功法破绽

- 诈唬组合过多。
- 价值范围不足。
- 河牌诈唬失败时损失较大。

### 破局心法

- 根据 Pot Odds（底池赔率）选择跟注。
- 优先使用带有合适阻断牌的抓诈唬牌。
- 保留其继续下注的空间，不急于加注。

## 四门辨要

青藤随行派的特征集中在翻牌前的跛入跟注；正一循矩院的特征是路线固定；潜龙伏渊宗以强牌示弱；千幻迷踪门则以弱牌示强。

> 行牌之迹，不在一招奇异，而在同一招反复出现。

## 本篇牌道术语

| 术语 | 简要释义 |
|---|---|
| Limp-Caller（跛入跟注型玩家） | 经常跛入，并在面对隔离加注后继续跟注的玩家。 |
| Limp Frequency（跛入频率） | 玩家获得跛入机会时选择跛入的比例。 |
| Isolation Raise（隔离加注） | 面对跛入者加注，试图减少入池人数并取得主动权。 |
| ABC Player（基础套路型玩家） | 主要依照直接、基础且变化有限的路线行牌的玩家。 |
| Trapper（设陷型玩家） | 经常以过牌或跟注隐藏强牌的玩家。 |
| Overbluffer（过度诈唬玩家） | 在特定节点放入过量诈唬组合的玩家。 |
| Betting Line（下注路线） | 一手牌中各轮行动与下注尺度组成的完整路径。 |
