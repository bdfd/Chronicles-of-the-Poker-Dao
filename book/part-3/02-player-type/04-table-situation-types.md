# 第二章第四篇：局势四门——筹码有深浅，人心随局变

同样一名玩家，携带100 BB（大盲）与150 BB（大盲）坐上牌桌时，能够使用的策略并不完全相同。

筹码越深，后续 Street（下注轮次）越多，Position Advantage（位置优势）、Nuts（坚果牌）、RIO（反向隐含赔率）与 Leverage（筹码杠杆）的影响便越明显。除了筹码深度，还应观察玩家的累计投入、持码习惯与调整能力。

局势四门不只记录怎样打牌，也记录一名玩家带着多少筹码入局、如何维持 Stack（筹码量），以及能否根据牌桌变化修改策略。

## 第一门：百炼定元堂

百炼定元堂对应 Standard-Stack Player（标准筹码玩家）。

其初始 Buy-in（买入）为100—120 BB（大盲）；筹码低于80 BB（大盲）时补码；至少80%的观察手数将 Stack（筹码量）维持在80—120 BB（大盲）。

此门以百盲为基，策略通常围绕常见的100 BB（大盲）结构展开。是否主动补码，也是识别其持码习惯的重要依据。

### 本门所长

- 常见 Spot（局面）较为熟悉。
- SPR（筹码底池比）变化相对稳定。
- 补码规则明确，策略容易执行。

### 功法破绽

- 面对更深筹码时调整不足。
- 容易机械套用百盲策略。
- 固定持码习惯可能暴露计划。

### 破局心法

- 每手牌先确认 Effective Stack（有效筹码）。
- 根据筹码底池比调整投入计划。
- 不以标准买入判断对手强弱。

## 第二门：渊海长策阁

渊海长策阁对应 Deep-Buy Player（深买入型玩家）。

其初始 Buy-in（买入）为130—150 BB（大盲）；至少80%的观察手数保持不低于120 BB（大盲）。只有当双方均持有至少120 BB（大盲）时，才把该手牌记录为较深 Effective Stack（有效筹码）局面。

一方拥有150 BB（大盲），另一方只有70 BB（大盲），双方实际能够相互投入的有效筹码仍然只有70 BB（大盲）。

### 本门所长

- 后续下注轮次的选择更多。
- 位置与坚果牌潜力价值更高。
- 强牌能够赢得更大底池。

### 功法破绽

- 错误会在多条下注轮次累积。
- 身处 OOP（不利位置）时压力更大。
- 弱顶对与弱同花承受更高反向隐含赔率。

### 破局心法

- 优先选择具有坚果牌潜力的起手牌。
- 减少用被支配牌构建大底池。
- 始终按照有效筹码规划行动。

## 第三门：金蟾万宝楼

金蟾万宝楼对应 Whale（高额娱乐玩家）。

归入此门需要同时满足以下条件：

- VPIP（主动入池率）不低于45%；
- 初始 Buy-in（买入）为150 BB（大盲）；
- 四小时内累计 Buy-in（买入）不低于450 BB（大盲）；
- 面对翻牌前 Raise（加注）的跟注率不低于60%。

单凭输掉三个买入，不能把一名玩家归入金蟾万宝楼。短期 Variance（波动）、Cooler（强牌碰撞）或连续 Bad Beat（坏运逆转），都可能造成相同结果。

### 本门所长

- 宽范围使具体牌力难以判断。
- 激进形象令强牌容易获得支付。
- 较深筹码能够制造较大压力。

### 功法破绽

- 平均起手牌强度不足。
- 弱牌与弱听牌投入过多。
- 情绪变化可能影响决策。

### 破局心法

- 争取 Position（位置）与有利座位。
- 以 Value Bet（价值下注）为主要收益来源。
- 严守 Bankroll Rule（资金管理规则）与 Stop-Loss（止损线）。

## 第四门：无相万化宗

无相万化宗对应 Adaptive Reg（适应型常客玩家）。

当对手连续3次使用同一种剥削动作后，此类玩家能在接下来5次相同或近似机会中至少调整2次；相邻两个50手窗口中，VPIP（主动入池率）、PFR（翻牌前加注率）或 3-Bet%（三次下注率）至少有一项变化不低于5个百分点，并有行动或 Showdown（摊牌）证据表明变化具有针对性。

无相万化宗最危险之处，是旧有 Read（读人判断）会迅速过期。

### 本门所长

- 能够识别重复出现的 Leak（漏洞）。
- 会根据 Table Dynamic（牌桌动态）改变策略。
- 善用 Table Image（牌桌形象）误导对手。

### 功法破绽

- 频繁调整会消耗注意力。
- 样本不足时可能过度调整。
- 仍受位置、范围与筹码限制。

### 破局心法

- 避免连续重复同一种剥削动作。
- 缩短更新 Opponent Profile（对手画像）的周期。
- 无明显 Edge（相对优势）时重新进行 Table Selection（选桌）。

## 四门辨要

百炼定元堂与渊海长策阁描述筹码结构；金蟾万宝楼同时描述投入规模与宽松打法；无相万化宗则描述随牌桌变化调整策略的能力。

> 局势不是背景。筹码深度、累计投入与相互调整，本身就是牌局的一部分。

## 本篇牌道术语

| 术语 | 简要释义 |
|---|---|
| Standard-Stack Player（标准筹码玩家） | 主要以100 BB（大盲）附近筹码深度参与牌局并主动补码的玩家。 |
| Deep-Buy Player（深买入型玩家） | 在100—150 BB（大盲）范围内选择较深初始买入的玩家。 |
| Whale（高额娱乐玩家） | 投入规模较大且通常采用宽松娱乐打法的玩家。 |
| Adaptive Reg（适应型常客玩家） | 能识别对手倾向并主动调整自身策略的常客玩家。 |
| Stack（筹码量） | 玩家当前在牌桌上可以投入的筹码总量。 |
| Effective Stack（有效筹码） | 两名玩家在一手牌中实际能够相互投入的最大筹码量。 |
| Buy-in（买入） | 玩家进入牌局时换取的初始筹码数量。 |
| BB（大盲） | 本章用于表示买入与筹码深度的统一单位。 |
