# 第二章第一篇：入局四门——未见翻牌，先辨来路

牌桌如山门，翻牌前的每一次投入，都是牌修留下的第一道足迹。

有人久守不出，只携强牌入局；有人择机拔剑，范围虽紧，进攻却不迟疑；有人踏遍诸峰，以宽广 Range（范围）频繁争夺主动；还有人刀势无度，无论牌力强弱皆欲掀起风雷。

欲辨其来路，应先观察 VPIP（主动入池率）、PFR（翻牌前加注率）与 3-Bet%（三次下注率）。三项数字分别显示一名玩家参与多少底池、主动发起多少进攻，以及面对前方加注时反击多少。

## 第一门：玄龟封山宗

玄龟封山宗对应 Nit（极紧玩家）。

此门中人常闭山门，极少主动入局。其 VPIP（主动入池率）为6%—12%，PFR（翻牌前加注率）为4%—9%，3-Bet%（三次下注率）为0%—3%，VPIP（主动入池率）与PFR（翻牌前加注率）相差不超过4个百分点。

若观察100手，只见其主动入池8手、翻牌前加注6手，便已显出封山之象。若其长久 Fold（弃牌）后突然从 EP（前位）Raise（加注），其 Range（范围）通常比普通玩家更强。

### 本门所长

- 入池范围强，少陷边缘局面。
- 行动纪律严，Variance（波动）较小。
- 强势线路可信，容易获得支付。

### 功法破绽

- Fold（弃牌）过多，盲注容易失守。
- 主动线路偏强，范围容易判断。
- 薄价值不足，错失部分收益。

### 破局心法

- 在其盲位前扩大 Open Raise（率先加注）。
- 面对多街强攻，减少边缘跟注。
- 若其面对 3-Bet（三次下注）弃牌不低于75%，适度增加三次下注诈唬。

## 第二门：玄衡剑宗

玄衡剑宗对应 TAG（紧凶玩家）。

此门讲究择机出剑。其 VPIP（主动入池率）为13%—22%，PFR（翻牌前加注率）为10%—18%，两者相差不超过5个百分点，3-Bet%（三次下注率）为4%—8%。

玄衡剑宗与玄龟封山宗的主要区别，不只在于入池数量，也在于主动性。两者都不会随意参与大量底池，但玄衡剑宗一旦决定入局，更愿意以 Raise（加注）、3-Bet（三次下注）与 C-Bet（持续下注）掌握主动。

### 本门所长

- 范围克制，主动性强。
- 重视 Position（位置）与下注逻辑。
- 基础稳固，很少出现大错。

### 功法破绽

- 路线固定时，容易被人识破。
- 部分节点可能弃牌过多。
- 面对非常规压力，调整速度有限。

### 破局心法

- 寻找具体漏洞，不与强范围硬碰。
- 重点观察 3-Bet Pot（三次下注底池）与 River（河牌）防守。
- 利用 Position Advantage（位置优势）减少正面压力。

## 第三门：游龙惊雷门

游龙惊雷门对应 LAG（松凶玩家）。

其 VPIP（主动入池率）为25%—38%，PFR（翻牌前加注率）为19%—31%，两者相差4—10个百分点，3-Bet%（三次下注率）为8%—14%。

游龙者参与的底池较多，却不是被动随行。他们善用 Position Advantage（位置优势），在 LP（后位）扩大 Open Range（率先加注范围），并通过连续下注迫使对手在多条 Street（下注轮次）作出困难决定。

### 本门所长

- 范围宽广，具体牌力难辨。
- 主动进攻多，能争取大量底池。
- 善借位置，持续制造压力。

### 功法破绽

- 平均牌力较弱。
- 进攻过多时，Bluff（诈唬）比例失衡。
- 身处 OOP（不利位置）时，宽范围难以兑现权益。

### 破局心法

- 收紧入局范围，但保留合理防守。
- 以偏价值的范围进行 3-Bet（三次下注）。
- 选择合适的 Bluff Catcher（抓诈唬牌）承接压力。

## 第四门：赤焰狂刀宗

赤焰狂刀宗对应 Maniac（极度激进玩家）。

其 VPIP（主动入池率）不低于45%，PFR（翻牌前加注率）不低于30%，3-Bet%（三次下注率）不低于15%；获得 Bet（下注）或 Raise（加注）机会时，至少65%的场合选择主动进攻。

狂刀与游龙看似相近，实则有别。游龙惊雷门以宽范围施压，却仍保留位置、牌面与范围逻辑；赤焰狂刀宗则可能在缺乏依据时继续扩大底池。

### 本门所长

- 攻势猛烈，Fold Equity（弃牌权益）较高。
- 牌力难辨，容易扰乱判断。
- 形象激进，强牌容易获得支付。

### 功法破绽

- 弱牌组合过多。
- Value Range（价值范围）不足以支撑攻势。
- 大底池频繁，Variance（波动）极高。

### 破局心法

- 减少 Bluff（诈唬），以 Value Bet（价值下注）为主。
- 持有强牌时，保留其继续进攻的空间。
- 严守 Effective Stack（有效筹码）与 Stop-Loss（止损线）。

## 四门辨要

玄龟封山宗与玄衡剑宗的差别，在于主动进攻频率；游龙惊雷门与赤焰狂刀宗的差别，则在于进攻是否仍有结构。

> 入局多少，观其宽窄；如何入局，观其攻守。

## 本篇牌道术语

| 术语 | 简要释义 |
|---|---|
| VPIP（主动入池率） | 玩家在翻牌前主动投入筹码参与底池的手数比例。 |
| PFR（翻牌前加注率） | 玩家在翻牌前至少进行一次加注的手数比例。 |
| 3-Bet%（三次下注率） | 玩家获得再次加注机会时选择加注的比例。 |
| Nit（极紧玩家） | 以极窄范围参与牌局的玩家。 |
| TAG（紧凶玩家） | 范围较紧且行动主动的玩家。 |
| LAG（松凶玩家） | 范围较宽且主动施压频率较高的玩家。 |
| Maniac（极度激进玩家） | 下注与加注频率远超正常范围的玩家。 |
