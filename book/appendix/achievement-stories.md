# 附录：道途成就札记

成就不是冰冷的名目，而是牌修曾经走过的一段路。本附录依照“凡品 → 稀有 → 史诗 → 传说”的品阶排列；每个品阶之下，再按九卷修行依次收录相应故事。

每则札记都与[第十卷第十一章：道途成就](../part-10/11-achievements.md)中的成就相连，并指向最适合继续参阅的正文或牌道术语。

## 凡品札记

### 第一卷：初入山门

<a id="achievement-01"></a>
#### 01｜初临试炼

第一次坐到牌桌前，我几乎听不清旁人的谈笑，只听见筹码碰撞时清脆的声响。那一晚我没有赢得多少灵石，却第一次完整经历了从发牌到离席的全过程，也终于承认自己尚有许多不懂。

> 对应修行：[第一卷第一章：初入山门](../part-1/01-entering-the-sect.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-02"></a>
#### 02｜识得五牌

公共牌摊开时，我一度把七张牌全部算进胜负，直到旁人指出最终只比较最佳五张。回去后，我把十种牌型逐一写进手札；第二次再遇相似牌面，终于没有看错。

> 对应修行：[第一卷第一章：初入山门](../part-1/01-entering-the-sect.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第二卷：灵石守护

<a id="achievement-03"></a>
#### 03｜账册初立

我曾只记得赢得最痛快的一局，却常忘记零散的损失。直到第一本账册写下日期、时长与盈亏，模糊的感觉才变成能够直视的数字。

> 对应修行：[第二卷第一章：灵石守护](../part-2/01-spirit-stone-guard.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-04"></a>
#### 04｜止损知返

那天离预定止损线只差一个买入，我仍相信下一手就能翻转局面。手放上筹码时，我想起入局前写下的约定，最终站起身来；第一次按计划离席，比一次翻本更难。

> 对应修行：[第二卷第一章：灵石守护](../part-2/01-spirit-stone-guard.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第三卷：观人识局

<a id="achievement-05"></a>
#### 05｜先观后断

新对手刚坐下时，我没有急着给他贴上松、紧、强或弱的标签。我先看完一轮行动，再把初步判断写进手札；少说一句定论，反而多看见了几分真实。

> 对应修行：[第三卷第一章：观人识局](../part-3/01-reading-the-table.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-06"></a>
#### 06｜行动留痕

一名沉默的对手在河牌亮出意外底牌，我第一次没有只顾着惊讶。我记下他的位置、下注尺度与摊牌结果，零散印象从此有了可以回查的痕迹。

> 对应修行：[第三卷第一章：观人识局](../part-3/01-reading-the-table.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第四卷：戒律道仪

<a id="achievement-07"></a>
#### 07｜守时入席

我为那次修行预先写下开始与结束的时刻。钟声到点时，无论盈亏都收起筹码；原来控制牌局时长，也是控制自己的一种方式。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-08"></a>
#### 08｜只行所学

我在别人的牌局中见过一种大胆术法，轮到自己时也想照搬。可我尚不明白它为何有效，最终选择弃用；不施展自己无法解释的招式，是我第一次尊重知识的边界。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-09"></a>
#### 09｜敬重执事

一次误会让我险些把怒气投向发牌员，话到嘴边却停了下来。我重新确认过程并平静沟通，才明白维护秩序的人不是输赢的替罪者。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-10"></a>
#### 10｜胜负有礼

赢下一只大底池时，我没有炫耀；输给一记河牌时，我也没有讥讽。简单的一句致意，让我记住桌边坐着的不是障碍，而是共同完成牌局的人。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第五卷：牌局历练

<a id="achievement-11"></a>
#### 11｜首夺灵池

那只底池并不大，我却记得最后一枚筹码被推到面前时的模样。真正值得记住的不是灵石数量，而是我第一次从观察、选择到摊牌，独自走完了一次决定。

> 对应修行：[第五卷第一章：牌局历练](../part-5/01-table-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-12"></a>
#### 12｜不战而胜

我拿着一手并不耀眼的牌，在合适的位置作出一次加注。对手沉思后弃牌，我没有亮出底牌；那时才明白，牌局争夺的不只是牌力，也包括信息与压力。

> 对应修行：[第五卷第一章：牌局历练](../part-5/01-table-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第六卷：术法精进

<a id="achievement-13"></a>
#### 13｜位置初悟

同样的底牌，坐在前位时让我进退失据，坐在后位时却能先看清众人行动。那一局之后，我第一次把座位当作信息，而不再只盯着手中的两张牌。

> 对应修行：[第六卷第一章：术法精进](../part-6/01-technique-mastery.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-14"></a>
#### 14｜尺度有度

从前下注，我只会凭紧张与兴奋随手抓取筹码。后来有一手牌，我在行动前说清了下注是为了什么、希望什么牌跟注；即便结果普通，这次下注终于有了尺度。

> 对应修行：[第六卷第一章：术法精进](../part-6/01-technique-mastery.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第七卷：心魔试炼

<a id="achievement-15"></a>
#### 15｜怒而不战

一记河牌让胜局化为乌有，我立刻想用下一手把灵石夺回。就在加注之前，我看见自己的手因愤怒而用力，便收回筹码弃牌；那一局未曾交锋，我却第一次赢过心魔。

> 对应修行：[第七卷第一章：心魔试炼](../part-7/01-inner-demon-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-16"></a>
#### 16｜输后离席

连续失利后，桌上的每个动作都像是对我的挑衅。我知道自己已经无法平静判断，于是收好剩余灵石离席；回望那张空椅子，我明白退一步也是一种修行。

> 对应修行：[第七卷第一章：心魔试炼](../part-7/01-inner-demon-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第八卷：复盘悟道

<a id="achievement-17"></a>
#### 17｜第一枚玉简

我把一手输掉的大底池重新写下，从翻牌前一直问到河牌。写到最后才发现，真正的问题早在第一轮下注时便已埋下；第一枚复盘玉简，也由此完成。

> 对应修行：[第八卷第一章：复盘悟道](../part-8/01-review-and-insight.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-18"></a>
#### 18｜记下疑局

那手牌结束时，我既说不清自己对在哪里，也说不清错在哪里。与其用结果替决定辩护，我把所有已知信息完整记下，留给更清醒的自己回答。

> 对应修行：[第八卷第一章：复盘悟道](../part-8/01-review-and-insight.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第九卷：长路飞升

<a id="achievement-19"></a>
#### 19｜初次月结

月末，我第一次把散落的牌局记录放在一起。盈亏只是其中一列，更重要的是我看见了反复出现的错误、进步与情绪，于是下个月终于有了明确方向。

> 对应修行：[第九卷第一章：长路飞升](../part-9/01-long-road-ascension.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-20"></a>
#### 20｜跨越低谷

低谷持续得比想象更久，我一度怀疑此前所学是否全无意义。暂停、复盘并降低风险后，我重新按计划坐回桌边；低谷没有消失，却不再替我作决定。

> 对应修行：[第九卷第一章：长路飞升](../part-9/01-long-road-ascension.md)｜[返回成就总章](../part-10/11-achievements.md)

## 稀有札记

### 第一卷：初入山门

<a id="achievement-21"></a>
#### 21｜盲注初识

我曾把盲注当作不得不交的费用，直到一次从按钮位观察完整轮转。那天我看懂了位置如何改变信息与选择，也第一次知道桌上的圆盘为何不断移动。

> 对应修行：[第一卷第一章：初入山门](../part-1/01-entering-the-sect.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-22"></a>
#### 22｜四街行者

一手牌从翻牌前走到河牌，我每一街都重新审视牌面与对手范围。最后虽然只赢得小池，却第一次感到自己不是被公共牌拖着走，而是在四条街上连续作出选择。

> 对应修行：[第一卷第一章：初入山门](../part-1/01-entering-the-sect.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第二卷：灵石守护

<a id="achievement-23"></a>
#### 23｜十次不越界

一次守住限额也许只是偶然，十次都守住才开始像纪律。第十次离席时，我在账册旁画下一笔，明白边界只有被反复遵守，才会成为真正的道基。

> 对应修行：[第二卷第一章：灵石守护](../part-2/01-spirit-stone-guard.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-24"></a>
#### 24｜灵石分仓

我把生活所需与牌局资金彻底分开，各自记账，不再互相填补。那一刻起，牌桌的波动无法直接侵入日常生活，灵石也终于有了清楚的边界。

> 对应修行：[第二卷第一章：灵石守护](../part-2/01-spirit-stone-guard.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第三卷：观人识局

<a id="achievement-25"></a>
#### 25｜修正旧判

我曾认定一名对手只会保守跟注，新出现的摊牌证据却与印象相反。与其为旧判断辩护，我划掉原有标签重新记录；承认看错，才让观察继续前进。

> 对应修行：[第三卷第一章：观人识局](../part-3/01-reading-the-table.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-26"></a>
#### 26｜不以貌取

衣着随意的新人坐下时，我下意识把他当成容易对付的玩家。几轮之后，清晰的尺度与稳定的节奏推翻了偏见；我输掉一池灵石，却丢掉了更昂贵的成见。

> 对应修行：[第三卷第一章：观人识局](../part-3/01-reading-the-table.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第四卷：戒律道仪

<a id="achievement-27"></a>
#### 27｜疲而知止

那晚没有明显亏损，我却发现自己已连续两次看错行动。身体仍坐在桌边，判断却早已离席；我收起筹码，把停止视为当晚最正确的一次决定。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-28"></a>
#### 28｜七日守戒

七日之内，我逐次核对开始时间、结束时间、级别和止损线。没有一项壮举值得炫耀，但七张完整记录叠在一起，第一次显出纪律的形状。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-29"></a>
#### 29｜不扰他人

道友面对艰难决定时向我投来询问的目光，我没有替他回答。牌局结束后我们再讨论那手牌；一手牌由一人独立完成，既守规则，也守彼此的成长。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-30"></a>
#### 30｜助新同修

新人分不清转牌与河牌，我没有在牌局进行时指点，只在休息后重新摆出牌面解释。看到他下一局能独立行动，我想起了自己第一次坐上牌桌的慌张。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第五卷：牌局历练

<a id="achievement-31"></a>
#### 31｜摊牌无悔

对手亮牌后，我输掉了当晚最大的底池。回看过程，我仍能说明每一街的理由；结果让我失去灵石，却没有推翻那个在当时信息下成立的决定。

> 对应修行：[第五卷第一章：牌局历练](../part-5/01-table-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-32"></a>
#### 32｜逆风守局

连输数局后，我把节奏放慢，重新核对级别、时长与止损线。逆风没有立刻停下，但我直到离席都没有偏离计划；那天守住的不是底池，而是自己的判断。

> 对应修行：[第五卷第一章：牌局历练](../part-5/01-table-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第六卷：术法精进

<a id="achievement-33"></a>
#### 33｜范围启蒙

过去我总问“他究竟是哪一手牌”，仿佛世间只有一个答案。后来我把所有合理组合铺在纸上，才明白推演不是猜中一张底牌，而是逐街缩小可能的范围。

> 对应修行：[第六卷第一章：术法精进](../part-6/01-technique-mastery.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-34"></a>
#### 34｜薄取灵石

河牌落下后，我的牌称不上强，却仍领先许多可能跟注的组合。我克制住免费摊牌的冲动，下了一记小注；被更差的牌跟注时，我第一次体会到薄价值的分量。

> 对应修行：[第六卷第一章：术法精进](../part-6/01-technique-mastery.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第七卷：心魔试炼

<a id="achievement-35"></a>
#### 35｜胜不忘形

一场大胜让我觉得自己忽然看懂了一切，甚至想立刻挑战更高境界。最终我仍按原计划收尾，并在次日照常复盘；好运没有被我误认成突破。

> 对应修行：[第七卷第一章：心魔试炼](../part-7/01-inner-demon-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-36"></a>
#### 36｜恐惧照见

我在河牌拿着明显可以取值的牌，却因害怕被加注而选择过牌。复盘时，我没有用“谨慎”美化退缩，而是第一次写下：这不是判断，是恐惧。

> 对应修行：[第七卷第一章：心魔试炼](../part-7/01-inner-demon-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第八卷：复盘悟道

<a id="achievement-37"></a>
#### 37｜找到错因

我原以为那手牌输在河牌运气，逐街回看才发现转牌下注已让自己的范围失去平衡。找到真正错因后，抱怨变成了下一次可以改变的行动。

> 对应修行：[第八卷第一章：复盘悟道](../part-8/01-review-and-insight.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-38"></a>
#### 38｜每周闭关

连续四周，我在同一晚关掉牌桌，只打开记录。起初闭关像额外负担，后来却成为一周中最安静的时刻，让零散经验逐渐连成道路。

> 对应修行：[第八卷第一章：复盘悟道](../part-8/01-review-and-insight.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第九卷：长路飞升

<a id="achievement-39"></a>
#### 39｜年度手札

一年的记录摊开时，我看见的不只是曲线，还有每个阶段反复出现的问题。那些当时以为跨不过去的低谷，如今都成了手札中的一页。

> 对应修行：[第九卷第一章：长路飞升](../part-9/01-long-road-ascension.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-40"></a>
#### 40｜传道一篇

我把一次真实失误连同思考过程公开写下，没有删去难堪，也没有把运气包装成修为。有人因此避开同样的坑时，这篇文字才真正有了传道的意义。

> 对应修行：[第九卷第一章：长路飞升](../part-9/01-long-road-ascension.md)｜[返回成就总章](../part-10/11-achievements.md)

## 史诗札记

### 第一卷：初入山门

<a id="achievement-41"></a>
#### 41｜独立决断

那场牌局没有朋友在身后提醒，也没有现成答案可以照抄。我为每次行动承担结果，结束后再逐一复盘；独立不是从不犯错，而是不再把选择交给别人。

> 对应修行：[第一卷第一章：初入山门](../part-1/01-entering-the-sect.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第二卷：灵石守护

<a id="achievement-42"></a>
#### 42｜风暴仍立

下行期接连而至，账册上的数字像风雨不断侵蚀道基。我降低级别、缩减场次并坚持复盘，等风暴过去时，灵石虽有损耗，生活与计划却仍完整。

> 对应修行：[第二卷第一章：灵石守护](../part-2/01-spirit-stone-guard.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第三卷：观人识局

<a id="achievement-43"></a>
#### 43｜三次验证

一次大额下注让我产生怀疑，但我没有立刻定论。直到相同尺度、相近牌面和最终摊牌三条线索互相印证，我才把观察写进对手画像。

> 对应修行：[第三卷第一章：观人识局](../part-3/01-reading-the-table.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第四卷：戒律道仪

<a id="achievement-44"></a>
#### 44｜一月无妄动

整整一个月，我没有因大胜升级，也没有因大败追损。计划有时显得沉闷，却替我挡住了无数临时冲动；月末回看，平静本身便是一种成绩。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-45"></a>
#### 45｜百局无争

百局之中有误会、有坏运，也有令人难堪的失误，我却没有一次把情绪倾倒给旁人。并非每次都心平气和，只是每次都选择了不伤害别人。

> 对应修行：[第四卷第一章：戒律道仪](../part-4/01-discipline-and-etiquette.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第五卷：牌局历练

<a id="achievement-46"></a>
#### 46｜千手磨砺

第一千手结束时，并没有雷声宣告境界突破。我翻看前后的记录，发现下注理由更清楚、情绪词更少；真正的磨砺，原来藏在这些细小变化里。

> 对应修行：[第五卷第一章：牌局历练](../part-5/01-table-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第六卷：术法精进

<a id="achievement-47"></a>
#### 47｜幻术得手

我在河牌没有成牌，却看见自己的范围保留着足够多的强牌。下注并非逞强，而是根据阻断牌、对手范围与尺度共同作出的选择；对手弃牌时，我知道这次幻术不是侥幸。

> 对应修行：[第六卷第一章：术法精进](../part-6/01-technique-mastery.md)｜[返回成就总章](../part-10/11-achievements.md)

### 第七卷：心魔试炼

<a id="achievement-48"></a>
#### 48｜贪念斩断

牌桌柔软、对手疲惫、筹码仍在流向我，继续留下似乎理所当然。但预定时刻已到，我仍选择离席；斩断贪念，不是在不利时逃走，而是在顺境中也记得边界。

> 对应修行：[第七卷第一章：心魔试炼](../part-7/01-inner-demon-trials.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-49"></a>
#### 49｜百局有档

第一百份复盘归档时，许多曾经孤立的错误开始重复出现。档案没有替我做决定，却让问题无处藏身；从此经验不再只靠记忆保存。

> 对应修行：[第八卷第一章：复盘悟道](../part-8/01-review-and-insight.md)｜[返回成就总章](../part-10/11-achievements.md)

<a id="achievement-50"></a>
#### 50｜九境圆满

九卷修行终于各亮起一枚印记，我却没有感到圆满无缺。它们更像九扇刚刚推开的门，提醒我牌道从来不是单线前行。
