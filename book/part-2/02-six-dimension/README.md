# 第二卷 第二章：六维照心

牌修若只以一时盈亏衡量自身境界，便容易将天时误认为修为，也可能把正常的 Variance（方差）视作实力衰退。真正可靠的自我评估，应当从六个彼此关联的维度展开：Skill（牌技）、Edge（相对优势）、Efficiency（实战转化效率）、Volume（有效手数）、Stake（牌局级别）与 Rake（抽水）。

Skill 衡量我掌握了多少能够解释、执行并复盘的扑克知识，包括 Range（范围）、Position（位置）、Bet Sizing（下注尺度）、Pot Odds（底池赔率）与 GTO（博弈论最优策略）等。Edge 则是相对概念：即使牌技没有改变，面对不同 Player Pool（玩家池）、对手构成与牌桌环境，我所拥有的优势也会发生变化。

Efficiency 检验我能否将所学稳定用于实战。知道正确策略，却在疲劳、恐惧或 Tilt（情绪失控）中无法执行，说明知识仍未完全转化为修为。Volume 则提供检验修为所需的 Sample Size（样本量）；但只有在决策质量没有明显下降时，增加的手数才属于 Effective Volume（有效手数）。

Stake 决定牌局的整体生态。不同级别拥有不同的对手倾向、下注强度与资金波动，我在低级别形成的策略，不能未经检验便直接用于更高境界。升级或降级也不应由一两场胜负决定，而应同时考虑 Bankroll（牌局资金）、长期 Win Rate（盈利率）与自身状态。

Rake 是试炼场持续收取的代价。不同 Online Cash Game（线上现金局）与 Live Cash Game（线下现金局）采用不同的抽水比例和 Rake Cap（抽水上限）。若 Edge 过于微弱，原本可能存在的盈利空间便会被抽水吞尽。因此，选择牌局时不仅要判断能否战胜对手，也要判断扣除成本后是否仍具有正向 Expected Value（期望值）。

六个维度并非六条互不相干的道路，而是一套共同运转的修行体系。Skill 决定我懂多少，Edge 决定所学在当前牌局中能产生多少优势，Efficiency 决定优势能够兑现多少，Volume 决定长期规律何时显现，Stake 决定所处环境与风险，而 Rake 则决定最终能够留下多少成果。

六维照心，不是为了替自己贴上强弱标签，而是为了看清当下最需要修补的道基。只有知道问题究竟出在知识、选局、执行、样本、级别还是成本，下一阶段的修行才不会误入歧途。
