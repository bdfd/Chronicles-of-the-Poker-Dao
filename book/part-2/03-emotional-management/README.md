# 第二卷 第三章：心湖守一——Emotional Management（情绪管理）

牌桌上的心魔，并不总在输掉筹码时现身。

有时，它藏在一次不愿认输的 Call（跟注）里；有时，它借勇气之名催促我 All-in（全下）；也有时，它让我为了摆脱沉闷，毫无依据地改变原本正确的打法。

真正的 Emotional Management（情绪管理），不是要求自己面对输赢毫无感觉，而是在情绪升起之后，仍能分辨什么是判断，什么只是冲动。

本章分为两篇：第一篇讨论关键时刻如何作出正确决定；第二篇讨论遭遇波动之后，如何调整心态与游戏节奏。
