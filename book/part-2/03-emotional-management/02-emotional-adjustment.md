# 第二卷 第三章 第二篇：心随局转——Emotional Adjustment（心态调整）

当足够多的手牌被发出，Bad Beat（坏运逆转）便不再是罕见异象，而是 Variance（方差）的正常组成。

领先的一方并不真正拥有底池，只是暂时拥有更高的 Equity（底池权益）。只要对手仍有 Outs（补牌张数），Turn（转牌）与 River（河牌）便可能改变结果。

道理并不复杂。真正困难的是在巨大底池被反超之后，仍然相信这个道理。

## 接受 Bad Beat（坏运逆转），而不改变正确打法

当 Whale（高额娱乐玩家）或 Maniac（极度激进玩家）用明显落后的 Range（范围）完成听牌时，我很容易产生不公之感：

明明我的决定更好，为什么筹码却去了他的面前？

如果不能接受概率带来的短期结果，我便可能在下一手牌中扩大 Range（范围）、增加 Bet Sizing（下注尺度），或急于与同一名对手再次形成大底池。此时我表面上仍在进行 Exploit（剥削），实际上只是想立刻夺回失去的灵石。

Bad Beat（坏运逆转）不会伤害下一手牌的 Equity（底池权益）。

真正改变下一手牌的，是我是否允许上一手的愤怒进入新的决定。

输掉大底池后，我不应立刻改变原有 VPIP（主动入池率）、提高 Stake（牌局级别）、增加 Buy-in（买入），或突破预先设定的 Stop-Loss（止损线）。

尤其在 Short Stack（短筹码）状态下，不能因为 Effective Stack（有效筹码）所剩不多，便把缺乏依据的 All-in（全下）当作唯一选择。筹码变短会改变合理的 Range（范围），却不会让任何两张牌突然获得 Positive EV（正期望值）。

## 大额失利后的五步调整

当情绪开始影响判断时，我需要依赖事先设定的程序，而不是临场说服自己继续。

### 第一步：暂停行动

在 Online Cash Game（线上现金局）中，可以选择 Sit Out（暂离）、关闭额外牌桌，或停止继续开新桌；在 Live Cash Game（线下现金局）中，可以离桌短暂休息，让自己离开筹码与对手带来的直接刺激。

暂停不是示弱，而是阻止情绪立即获得下一次下注权。

### 第二步：只记录事实

记下 Hole Cards（底牌）、Community Cards（公共牌）、Position（位置）、Effective Stack（有效筹码）与 Betting Line（下注路线），不急于写“太倒霉”“对手乱打”或“我本该赢”。

事实能够被复盘，情绪化评价只会让记忆进一步偏斜。

### 第三步：检查四级竞技状态

每次经历大底池或连续失利后，我都需要判断自己正处于哪一种状态：

- **S-Game（最佳竞技状态）**：注意力集中，情绪稳定，能够完整分析 Range（范围）、Position（位置）、Bet Sizing（下注尺度）与 Effective Stack（有效筹码）。
- **A-Game（普通竞技状态）**：整体判断仍然可靠，但专注度或执行力略有下降，需要放慢节奏，减少不必要的复杂决定。
- **B-Game（失常竞技状态）**：已经出现扩大 VPIP（主动入池率）、频繁 Hero Call（英雄式跟注）、缩短思考时间，或针对特定玩家进行报复性行动等迹象。此时应当 Sit Out（暂离），停止增加牌桌并重新评估状态。
- **C-Game（必须即刻离场的状态）**：已经无法遵守原定 Range（范围）、Bankroll Rule（资金管理规则）或 Stop-Loss（止损线），并出现 Chase Losses（追损）、冲动 All-in（全下）或提高 Stake（牌局级别）的行为。进入这一状态后，不再进行自我说服，必须立即结束 Session（牌局场次）并离场。

S-Game（最佳竞技状态）可以主动寻找机会；A-Game（普通竞技状态）需要降低决策复杂度；B-Game（失常竞技状态）必须暂停；C-Game（必须即刻离场的状态）则没有继续游戏这一选项。

状态划分不是为了替情绪取一个好听的名字，而是为了让离场标准先于情绪存在。

### 第四步：守住 Daily Buy-in Cap（每日买入上限）

每天开始第一场 Session（牌局场次）之前，必须预先写下 Daily Buy-in Cap（每日买入上限）。

这个上限可以按照固定金额设定，也可以按照 Standard Buy-in（标准买入）的数量设定。Online Cash Game（线上现金局）需要合并计算所有牌桌的 Buy-in（买入）与 Rebuy（重新买入）；Live Cash Game（线下现金局）则需要计算当日所有换桌、补码与重新入场所投入的筹码。

Daily Buy-in Cap（每日买入上限）一旦确定，当天便不得因为以下理由临时提高：

- 牌桌看起来十分有利；
- Whale（高额娱乐玩家）仍未离场；
- 刚刚遭遇 Bad Beat（坏运逆转）；
- 认为下一次 Buy-in（买入）便能追回损失；
- 当日稍早曾经盈利；
- 不愿以亏损结束当天的 Session（牌局场次）。

当累计买入达到 Daily Buy-in Cap（每日买入上限）时，必须停止 Rebuy（重新买入）并立即离场。

Daily Buy-in Cap（每日买入上限）与 Stop-Loss（止损线）可以共同存在：前者限制当日最多能够投入多少筹码，后者规定当亏损达到何种程度时必须停止。二者一旦触发，均不得因牌桌环境或个人情绪临时上调。

规则应在情绪出现之前制定，也必须在情绪最强烈时继续有效。

### 第五步：必要时结束 Session（牌局场次）

若短暂休息后仍无法清楚说明对手的 Range（范围）、Betting Purpose（下注目的）与继续游戏的理由，那么当日最好的决定可能不在牌桌之内。

进入 C-Game（必须即刻离场的状态）、达到 Daily Buy-in Cap（每日买入上限），或触发 Stop-Loss（止损线）后，都必须立即结束 Session（牌局场次）。

结束 Session（牌局场次）不是向 Variance（方差）低头，而是拒绝让一次坏结果演变成一连串坏决定。

## 调整节奏，不是随机改变打法

为了不被对手看透，我曾刻意让自己时而松、时而紧。

有时开局便扩大 Range（范围），希望建立 Loose Image（松散形象）；等对手开始轻视我的下注后，再突然收紧 Range（范围），以强牌获得更多支付。

这种方法在特定牌桌上可能有效，却不能成为固定公式。

如果我只为了“让人猜不透”而不断改变策略，自己的行动首先会失去依据。真正的 Adjustment（策略调整），应当来自牌桌正在发生的变化。

面对 Loose Player（宽松玩家），我可以减少边缘 Bluff（诈唬），更重视 Value Bet（价值下注）；面对 Tight Player（紧弱玩家），则可以在合适的 Position（位置）扩大 Steal Range（偷盲范围），主动争夺 Dead Money（死钱）。

若对手开始针对我的频繁 Open Raise（率先加注）进行 3-Bet（三次下注），我便需要重新检查 Opening Range（率先加注范围）与 4-Bet Strategy（四次下注策略）；若对手只在强牌出现时进行大额下注，我也应减少不必要的 Bluff Catch（抓诈唬）。

变化的目的不是制造混乱，而是让自己的策略继续适应对手。

高明的节奏不是每隔几圈换一种打法，而是在 Table Dynamic（牌桌动态）发生改变时，我能比别人更早察觉，也更快完成 Adjustment（策略调整）。

## Table Image（牌桌形象）不是表演

每一次 Showdown（摊牌），都会影响对手如何看待我。

若我曾以边缘牌进行大胆 Bluff（诈唬），之后的 Value Bet（价值下注）可能得到更多 Call（跟注）；若我长时间没有参与底池，下一次 Raise（加注）也可能获得更多尊重。

这便是 Table Image（牌桌形象）的价值。

但 Table Image（牌桌形象）应当来自真实且合理的行动，而不是为了建立某种形象，故意进行 Negative EV（负期望值）操作。用毫无胜算的牌扔掉大量筹码，再期待未来某手强牌获得支付，往往只是为眼前错误编造长期理由。

利用 Table Image（牌桌形象）之前，我需要先问：

- 桌上哪些对手真正注意到了此前行动；
- 他们是否有能力根据 Table Image（牌桌形象）作出 Adjustment（策略调整）；
- 他们可能如何调整；
- 我能否利用这种调整获得未来价值。

Online Cash Game（线上现金局）的玩家流动更快，Zoom（快速桌）或 Fast-Fold（快速弃牌桌）中的对手甚至可能很快消失。此时刻意经营 Table Image（牌桌形象）的价值有限，Player Pool Tendency（玩家池倾向）与稳定策略往往更加重要。

Live Cash Game（线下现金局）中，对手相处时间更长，桌面交流与 Showdown（摊牌）记忆也更加明显，Table Image（牌桌形象）才更可能在后续底池中持续产生作用。

Table Image（牌桌形象）可以利用，却不值得膜拜。最终决定我是否下注的，仍应是当前 Spot（局面）的 Expected Value（期望值）。

## 根据对手调整松紧

面对不同玩家，我需要采取不同节奏。

如果桌上玩家普遍过于宽松，愿意用大量弱牌 Call（跟注），那么我应减少缺乏 Fold Equity（弃牌权益）的 Bluff（诈唬），收紧部分边缘 Range（范围），并使用更清晰的 Value Bet（价值下注）策略。

如果牌桌整体过紧，许多玩家面对 Raise（加注）轻易 Fold（弃牌），那么我可以在 Late Position（后位）扩大 Opening Range（率先加注范围），争夺无人主动保护的 Dead Money（死钱）。

但“对手松，我便紧；对手紧，我便松”只是一条起点，不是完整答案。

我还需要考虑：

- 自己与目标玩家之间的 Relative Position（相对位置）；
- Effective Stack（有效筹码）与 Stack Depth（筹码深度）；
- 对手在 Preflop（翻牌前）与 Postflop（翻牌后）的具体 Leak（漏洞）；
- Rake（抽水）对边缘入池的影响；
- 当前 Table Image（牌桌形象）是否已经改变对手的反应。

Adjustment（策略调整）必须落到具体 Range（范围）与具体行动，不能只停留在“今天打松一点”或“这一桌要稳一点”的模糊感觉上。

## Short-Handed Table（非满员桌）的节奏

当玩家陆续离席，牌桌从满员变成 Short-Handed Table（非满员桌）时，Blinds（盲注）会更频繁地来到面前。

如果我仍然使用满员桌的 Range（范围），便可能因过度等待而持续损失 Blinds（盲注）。但这不意味着应该因为“很久没有好牌”便随意参与游戏。

玩家减少后，BTN（庄位）、SB（小盲位）与 BB（大盲位）的对抗更加频繁，Opening Range（率先加注范围）、3-Bet Range（三次下注范围）与 Blind Defense（盲位防守范围）通常需要相应调整。

与此同时，我还要重新评估：

- 剩余玩家是否明显强于自己；
- 自己是否熟悉更宽 Range（范围）之间的 Postflop（翻牌后）对抗；
- 当前 Seat（座位）是否仍有 Position Advantage（位置优势）；
- Rake（抽水）在 Short-Handed Table（非满员桌）中的实际影响；
- 继续游戏是否优于暂时离桌等待。

参与更多底池与盲目扩大 Range（范围）并不是同一件事。

若我能够说明为什么 Range（范围）应当改变，那是 Adjustment（策略调整）；若只是因为无聊、焦虑或不愿被洗盲而入池，那仍然是心魔。

## Blind Size（盲注规模）必须结合 Effective Stack（有效筹码）

判断边缘牌是否值得参与，不能只看 Blind Size（盲注规模）的绝对金额。

真正影响策略的，是 Blind Size（盲注规模）、Buy-in（买入）、Effective Stack（有效筹码）、底池大小与 Stack-to-Pot Ratio（筹码底池比）之间的关系。

同样是1/2的 Live Cash Game（线下现金局），100BB（100个大盲）与300BB（300个大盲）深度下的策略可以相差很大。更深的 Stack Depth（筹码深度）会提高 Position Advantage（位置优势）的价值，也会放大后续 Street（下注轮次）中的决策难度。

底池中存在更多 Dead Money（死钱）时，一些边缘牌可能获得更好的 Pot Odds（底池赔率）或 Implied Odds（隐含赔率），但“底池已经很大”本身并不足以支持参与。

我仍要判断：

- 自己是否拥有足够 Equity（底池权益）；
- 是否能够在当前位置实现这些 Equity（底池权益）；
- 对手的 Range（范围）是否让我拥有合理的 Implied Odds（隐含赔率）；
- 击中中等牌力后，是否容易遭遇 Reverse Implied Odds（反向隐含赔率）；
- Rake（抽水）是否已经吞噬原本微弱的利润。

边缘牌之所以难，不是因为它们永远不值得游戏，而是它们需要更准确的条件。

## 拥抱 Variance（方差），而不向 Variance（方差）屈服

扑克是一个概率游戏。

只要继续修行，我便不可能避开 Bad Beat（坏运逆转）、Cooler（强牌碰撞）与 Downswing（下风期）。试图消灭所有 Variance（方差），只会让我变得畏缩；假装自己不受 Variance（方差）影响，则会让我看不见心魔已经进入决定。

真正的平静，不是输掉巨大底池时毫无感觉。

它是在感到愤怒、遗憾与不甘之后，仍然知道下一步应该做什么；是在一次错误后愿意承认错误，也在一次正确决定遭遇坏结果时，不急于推翻原有策略。

我无法控制下一张 River（河牌）会落下什么。

能够控制的，是每次行动前是否仍愿意核对 Range（范围）、Position（位置）、Effective Stack（有效筹码）与 Bet Sizing（下注尺度）；是失去一只底池之后，是否仍把下一手牌视作一场新的决定；也是在判断力已经离席时，自己是否有勇气跟着离开。

守住心湖，并非让水面从此无波。

而是风浪来时，我仍看得见方向。

## 本篇三省

1. 遭遇 Bad Beat（坏运逆转）或大额亏损后，我是否擅自改变了 VPIP（主动入池率）、Stake（牌局级别）、Buy-in（买入）、Stop-Loss（止损线）或 Daily Buy-in Cap（每日买入上限）？
2. 我对 Range（范围）、Table Image（牌桌形象）与游戏节奏作出的 Adjustment（策略调整），来自可以验证的 Table Dynamic（牌桌动态），还是来自无聊、焦虑与报复冲动？
3. 我目前处于 S-Game（最佳竞技状态）、A-Game（普通竞技状态）、B-Game（失常竞技状态）还是 C-Game（必须即刻离场的状态）；若已经达到 Daily Buy-in Cap（每日买入上限）或进入 C-Game（必须即刻离场的状态），是否立即结束了 Session（牌局场次）？
